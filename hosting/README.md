# Хостинг «3D-вебка по ссылке»

Сервис: пользователь по персональной ссылке-приглашению загружает STEP, 3D-PDF (PRC), NWD или GLB и получает адрес страницы с интерактивной 3D-моделью (вращение, дерево деталей, сечения, ссылка на настроенный вид). Регистрации и личных данных нет. Страница хранится 30 дней с продлением, исходный файл удаляется сразу после конвертации.

Состав: `caddy` (TLS, статика `/m/<id>/`), `app` (FastAPI: загрузка, список, продление, удаление), `worker` (конвертация, чистка). Данные — SQLite + каталог `/data`.

## Что принимаем

| Формат | Проверка | Предел (МБ, `.env`) |
|---|---|---|
| STEP / STP | расширение + `ISO-10303-21` | 100 |
| PDF с 3D (PRC) | расширение + `%PDF` | 100 |
| NWD | расширение + `#LcUStream` | 300 |
| GLB | расширение + `glTF`, один буфер, без внешних `uri` | 60 |

Неподдерживаемое расширение — отказ 400 до записи тела; заявленный `Content-Length` сверх предела — 413 до чтения тела (если фактически записано больше предела — 413 и удаление файла); несовпадение первых байтов с форматом выясняется уже после записи тела целиком — файл удаляется, ответ 400. Квоты на приглашение: 30 моделей, 10 загрузок в сутки; при занятости диска выше 85 % загрузка отклоняется. Результат (GLB) не больше 60 МБ, иначе конвертация помечается `failed` с причиной.

Исходный файл никому не отдаётся (отдаётся только сгенерированный GLB), поэтому антивирусная проверка загрузок не выполняется — это осознанное решение. Имена деталей и источников внутри модели остаются в GLB.

## Требования к серверу

Ubuntu 24.04, 2 vCPU, 4 ГБ ОЗУ, 20 ГБ диска. Для NWD нужен своп 2 ГБ (его создаёт `install.sh`): пик памяти конвертера крупной модели — около 3 ГБ; у контейнера `worker` лимит 2 ГБ + 2 ГБ свопа.

## Установка

1. DNS: запись A `3d.<ваш-домен>` → IP сервера (проверяется скриптом до запуска).
2. Сначала добавьте SSH-ключ и проверьте вход по нему; `install.sh` настройки `sshd` не меняет.
3. На сервере:

```bash
git clone https://github.com/VibeEngineering-LLC/step-nwd-web-viewer.git
cd step-nwd-web-viewer/hosting
cp .env.example .env      # заполнить DOMAIN и ACME_EMAIL
sudo ./install.sh
```

4. Создать приглашение (ссылка показывается один раз, в БД хранится хеш):

```bash
docker compose exec app viewerctl invite add "Иван, проект А"
```

## Администрирование (`viewerctl`)

```bash
docker compose exec app viewerctl invite list
docker compose exec app viewerctl invite revoke <id> [--purge]
docker compose exec app viewerctl models list
docker compose exec app viewerctl models delete <id>
docker compose exec app viewerctl stats
```

## Если что-то не работает

```bash
docker compose ps
docker compose logs --tail 100 worker
docker compose restart worker
docker compose exec app viewerctl stats
df -h
```

Обновление: `git pull && docker compose up -d --build`, затем `docker image prune`.

## Безопасность

Порты наружу публикует только `caddy` (80/443); TLS 1.2/1.3; заголовки HSTS, CSP, `nosniff`, `Referrer-Policy: no-referrer`; контейнеры без root, `read_only`, `no-new-privileges`; three.js внутри образа, ссылки на Google Fonts из страниц удаляются, шрифты не поставляются (используются системные; внешних запросов у зрителя нет); токены и `id` — `secrets.token_urlsafe(16)`; access-лог app выключен (токен в пути). Название модели экранируется для HTML и JS.

## Лицензии и ограничения применения

- **PyMuPDF — AGPL-3.0:** по §13 пользователям сервиса по сети нужно предложить исходный код; в подвале страницы загрузки дана ссылка на этот репозиторий.
- **nwd-reader (парсер NWD) не имеет лицензии.** В репозиторий он не входит: образ собирает его из GitHub на закреплённом коммите при `WITH_NWD=1`. Решение о применении парсера без лицензии принимает владелец сервера; `WITH_NWD=0` собирает образ без NWD.
- Остальное — `../THIRD_PARTY.md`.

## Тесты

Сначала соберите тестовый образ с тегом, который ждут скрипты: `docker build -f hosting/Dockerfile --target test -t viewer-test:pinned .` (из корня репозитория). Затем `hosting/run-tests.ps1` (Windows, Docker) либо `docker compose -f hosting/docker-compose.test.yml run --rm tester`: тесты идут в контейнере без сети; `run-tests.ps1` пишет лог в `hosting/gen/pytest.log`.

## Ограничения

Одна конвертация за раз (крупный NWD — 1–3 мин); резервных копий страниц нет; антивируса загрузок нет; рассчитано на узкий круг доверенных пользователей по секретным ссылкам.
