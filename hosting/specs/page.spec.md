Write a complete Python 3.12 module `page.py` (stdlib only: html, json, re, time, datetime; no markdown fences, no explanations, output ONLY code). Docstring and comments in Russian. Imported as `from . import config` inside package `hosting_app`.

Purpose: turn the viewer template (an HTML FRAGMENT without doctype/head/body, containing the placeholders `{{TITLE}}`, `{{SUBTITLE}}`, `{{MODEL_NAME}}`) into a complete safe HTML document. User-supplied titles must never break the page or inject script.

## Functions
1. `html_escape(s)` -> `html.escape(s, quote=True)`.
2. `js_escape(s)` -> text safe to put INSIDE a JavaScript string literal delimited by single quotes that is itself inside an HTML `<script>` element: escape backslash first, then `'`, `"`, backtick, newline, carriage return, tab, U+2028, U+2029, and ALSO `<`, `>`, `&` as `<`, `>`, `&`; all as backslash sequences (`\\`, `\'`, `\"`, `\``, `\n`, `\r`, `\t`, ` `, ` `). The result must contain no raw `<`, `>`, `&`, quotes, backtick, backslash except as the start of an escape.
3. `clean_title(raw, fallback="Модель")` -> strip control characters (category Cc/Cf except nothing is kept), collapse whitespace runs to one space, strip, cut to 80 characters; empty -> `fallback`.
4. `fill_template(fragment, title, subtitle)` -> replace `{{TITLE}}` and `{{SUBTITLE}}` with `html_escape(...)` and `{{MODEL_NAME}}` with `js_escape(title)`. Order matters: perform a single pass with `re.sub(r"\{\{(TITLE|SUBTITLE|MODEL_NAME)\}\}", fn, text)` so replacement text containing `{{...}}` is never re-substituted.
5. `localize_vendor(text)` -> make the page free of external requests: (a) replace the import map entries so that `https://cdn.jsdelivr.net/npm/three@0.160.0/build/three.module.js` becomes `/vendor/three/build/three.module.js` and `https://cdn.jsdelivr.net/npm/three@0.160.0/examples/jsm/` becomes `/vendor/three/examples/jsm/`; (b) remove every `<link ...>` element whose href starts with `https://fonts.googleapis.com` or `https://fonts.gstatic.com` (regex over the whole `<link ...>` tag, case-insensitive). Must be idempotent.
6. `wrap_document(fragment, title, expires_ts, fix_prc=False, subtitle="")` -> full document string:
   `<!doctype html>\n<html lang="ru">\n<head>\n<meta charset="utf-8">\n<meta name="viewport" content="width=device-width, initial-scale=1, viewport-fit=cover">\n<meta name="robots" content="noindex,nofollow">\n<meta name="referrer" content="no-referrer">\n` + (`<script>window.FIX_PRC_MESH=true;</script>\n` if fix_prc) + the fragment passed through `fill_template(...)` then `localize_vendor(...)` + `\n<div id="shareFooter" style="position:fixed;left:8px;bottom:6px;font:11px/1.3 system-ui,sans-serif;opacity:.65;z-index:5;pointer-events:auto">Доступно до DD.MM.YYYY · <a href="SOURCE_URL" rel="noopener noreferrer" target="_blank" style="color:inherit">исходный код</a></div>\n</body>\n</html>\n`. The date is `expires_ts` formatted `%d.%m.%Y` in UTC; `SOURCE_URL` is `html_escape(config.SOURCE_URL)`. The fragment's own `<title>` stays where it is (the template starts with it).

No other behavior; no file I/O.
