Write a complete Python 3.12 module `convert.py` (stdlib only: os, sys, re, json, struct, shutil, subprocess, signal, tempfile; no markdown fences, no explanations, output ONLY code). Docstring and comments in Russian. Imported as `from . import config, page` inside package `hosting_app`. User-visible error messages (in `ConvertError`) are in Russian, short, without paths.

## Exceptions and helpers
- `class ConvertError(Exception)` — message is shown to the end user.
- `run(cmd, cwd, timeout=None)` -> `(returncode, output_text)`. `cmd` is a list. Start with `subprocess.Popen(cmd, cwd=cwd, stdout=PIPE, stderr=STDOUT, start_new_session=True, env=clean_env)` where `clean_env` contains only `PATH` (from os.environ), `HOME`=cwd, `LANG`=`C.UTF-8`, `PYTHONIOENCODING`=`utf-8`, `PYTHONDONTWRITEBYTECODE`=`1`. `timeout` defaults to `config.TASK_TIMEOUT_S`. On `subprocess.TimeoutExpired` kill the WHOLE process group (`os.killpg(proc.pid, signal.SIGKILL)`), reap it, and raise `ConvertError("Превышено время обработки")`. Output decoded as utf-8 with `errors="replace"`, truncated to the last 20000 characters.
- `inspect_glb(path)` -> dict `{"nodes": int, "meshes": int, "vertices": int, "root": str, "external_uri": bool, "buffers": int}` by parsing the GLB header (magic `glTF`, version 2), the first chunk must be type `JSON`; vertices = sum of `accessors[p.attributes.POSITION].count` over all primitives of all meshes; `root` = name of the first node of `scenes[scene or 0].nodes` (empty string if none); `external_uri` is True when any entry of `buffers` or `images` has a `uri` that does not start with `data:`; `buffers` = number of entries of `buffers`. Any structural problem (short file, wrong magic, bad JSON) raises `ConvertError("Файл GLB повреждён")`.
- `check_glb(path, max_mb)` -> inspect result; raises `ConvertError` with messages: no meshes or zero vertices -> `"В модели не найдено геометрии"`; size above `max_mb` megabytes -> `"Страница получилась слишком тяжёлой (N МБ, предел M МБ)"`.

## Converters (each takes the source file path and a work directory `work`, writes `work/model.glb`, returns nothing)
- `conv_step(src, work)`: run `[config.PYTHON, SCRIPTS/step2glb.py, src, glb, tol]` with `tol` taken from the sequence `"0.5"`, `"2.0"`, `"5.0"`: after each run call `check_glb` on the file; if only the size check failed and tolerances remain, retry with the next tolerance, otherwise raise. A non-zero return code or missing output file raises `ConvertError("Не удалось прочитать STEP")`.
- `conv_pdf(src, work)`: run `[PYTHON, SCRIPTS/prc/prc2glb.py, src, glb, work/"prcwork"]`. Parse the output: `Leaf parts with mesh: N` (regex) must give N > 0 and the output must contain the line `Missing leaf parts: none`; else raise `ConvertError("В PDF не найдена 3D-модель PRC или она не разобрана")`. Return code must be 0.
- `conv_nwd(src, work)`: `dump = work/"dump"`; run `[config.NWD_DUMP, src, dump]` (rc 0 else `ConvertError("Не удалось прочитать NWD")`); run `[PYTHON, SCRIPTS/nwd/nwd2glb.py, dump, glb, work/"report.json"]`; run `[PYTHON, SCRIPTS/nwd/check_area.py, dump, glb]`: rc must be 0 AND the output must contain at least one line matching `GLB [\d.]+ м2` else `ConvertError("Проверка площадей модели не пройдена")`; if the glb size exceeds `config.QUANTIZE_ABOVE_MB` megabytes run `[PYTHON, SCRIPTS/nwd/quantize_glb.py, glb, work/"q.glb"]` and, on rc 0, replace `glb` with `q.glb` (`os.replace`).
- `conv_glb(src, work)`: `info = inspect_glb(src)`; raise `ConvertError("GLB ссылается на внешние файлы — загрузите автономный GLB")` if `external_uri` or `buffers > 1`; copy to `glb`.

## Entry point
`convert(kind, src, work, page_dir, title, expires_ts)` -> `{"parts": int, "size_glb": int}`:
1. `os.makedirs(work, exist_ok=True)`; dispatch to the converter by `kind` (`step|pdf|nwd|glb`; unknown -> `ConvertError`).
2. `info = check_glb(glb, config.MAX_GLB_MB)`; `parts` = number of nodes in the GLB that have a `mesh` (count by parsing the JSON again, or extend `inspect_glb` with key `mesh_nodes` — your choice, but `parts` must be that count, at least 1).
3. Root rename: if `info["root"]` is non-empty, run `[PYTHON, SCRIPTS/glb_rename_root.py, glb, work/"r.glb", info["root"], page.clean_title(title)]` and on rc 0 replace the glb with `r.glb`.
4. Build the page fragment: for `nwd` run `[PYTHON, SCRIPTS/nwd/build_viewer.py, ASSETS/"viewer-template.html", ASSETS/"section_module.js", work/"frag.html", "-", "-"]` (rc 0 required) and read `frag.html`; for other kinds read `ASSETS/viewer-template.html` directly (utf-8).
5. `doc = page.wrap_document(fragment, page.clean_title(title), expires_ts, fix_prc=(kind == "pdf"), subtitle="Просмотр модели")`.
6. Publish atomically: create a temp directory with `tempfile.mkdtemp(dir=os.path.dirname(page_dir))`, write `index.html` (utf-8) and move `model.glb` into it, `os.chmod` the directory to 0o755 and files to 0o644, remove `page_dir` if it already exists, then `os.rename(tmp, page_dir)`. On any exception remove the temp directory and re-raise.
7. Return `{"parts": parts, "size_glb": os.path.getsize(final glb)}`.
Never log or put into error messages the source path or the user's file name.
