Write a complete Python 3.12 module `worker.py` (stdlib only; no markdown fences, no explanations, output ONLY code). Docstring and comments in Russian. Imported inside package `hosting_app` as `from . import config, db, convert`. Run as `python -m hosting_app.worker`.

## Available db functions (the ONLY ones that exist; do not invent others)
`db.init`, `db.claim_next(conn)`, `db.finish_model(conn, id, status, size_glb=None, parts=None, error=None)`, `db.reset_running(conn)`, `db.expired_models(conn, now)`, `db.stale_failed(conn, days, now)`, `db.stale_uploading(conn, hours, now)`, `db.delete_model(conn, id)`, `db.all_model_ids(conn)` -> set of ids, `db.active_model_ids(conn)` -> set of ids in status uploading/queued/running. Row objects are `sqlite3.Row` (index by column name; there is NO `.get`). In `except Exception as e:` blocks always bind the exception (`as e`) before using it.

## Functions
- `process_one(conn)` -> bool: `row = db.claim_next(conn)`; if None return False. Otherwise compute `src` = the single file `config.INCOMING/<id>/src.*` (glob; if absent -> fail with `"Исходный файл не найден"`), `work = config.WORK/<id>`, `page_dir = config.PAGES/<id>`. In `try`: `res = convert.convert(row["kind"], src, work, page_dir, row["title"], row["expires_at"])`; then `db.finish_model(conn, id, "done", size_glb=res["size_glb"], parts=res["parts"])`. `except convert.ConvertError as e`: `db.finish_model(conn, id, "failed", error=str(e))`. `except Exception`: `db.finish_model(conn, id, "failed", error="Внутренняя ошибка обработки")` and print the exception class name to stdout (no paths, no tokens). In `finally` ALWAYS remove `config.INCOMING/<id>` and `config.WORK/<id>` with `shutil.rmtree(..., ignore_errors=True)`. Return True.
- `cleanup_once(conn, now=None)` -> dict counts `{"expired": n, "stale_dirs": n, "failed_rows": n}`:
  1. for every row in `db.expired_models(conn, now)`: remove `config.PAGES/<id>`, `config.INCOMING/<id>`, `config.WORK/<id>` then `db.delete_model`.
  2. for every subdirectory of `config.INCOMING` and `config.WORK` whose mtime is older than 24 hours relative to `now` AND whose name is not in `db.active_model_ids(conn)`: remove it. Also: for every row in `db.stale_uploading(conn, 1, now)` remove its `config.INCOMING/<id>` directory and `db.delete_model` (interrupted uploads).
  3. for every row in `db.stale_failed(conn, 7, now)`: remove its directories and `db.delete_model`.
  4. directories in `config.PAGES` whose name is NOT in `db.all_model_ids(conn)` (orphans) and whose mtime is older than 1 hour relative to `now`: remove. SAFETY: a directory whose name IS in `all_model_ids` must never be removed here, whatever its age (never compute the set from a query that can silently fail).
- `main()`: `conn = db.init()`; `db.reset_running(conn)`; create the directories `INCOMING`, `WORK`, `PAGES` (mode 0o755); print `worker started`; loop forever: `if not process_one(conn): time.sleep(2)`; every 3600 seconds (monotonic clock) call `cleanup_once`; catch `KeyboardInterrupt` and exit cleanly; any other exception inside one iteration is printed as class name only and the loop continues after 5 seconds.

`if __name__ == "__main__": main()`.
