# NWD (Navisworks) → веб-страница с сечениями

Отработано на крупном реальном файле NWD (цепочка из десятков вложенных версий; инженерные системы и архитектура; десятки тысяч экземпляров, около миллиона треугольников).

## Формат (по результатам разбора файла)

- Заголовок `#LcUStream-V1.1 binary double release C lichunk-008`, далее zlib-блоки (`78 9c` / `78 da`) по 64 КБ. Публичной спецификации нет.
- Открытый парсер: `github.com/1817716374/nwd-reader` (C++20). **Лицензии у него нет** — в этот репозиторий он не входит; склонируйте сами и проверьте код до сборки и запуска.
- Сборка дампера: MSVC 2022 или GCC/Clang с C++20, CMake ≥ 3.20, `-DNWD_READER_DIR=<клон>`; свой `scripts/nwd/CMakeLists.txt`.

## Порядок

1. `nwd_dump model.nwd out/` → `scene.json` (узлы, экземпляры с матрицами и индексом системы `IfcSystem`, геометрии, `overrides`) и `geoms.bin` (вершины float32 и индексы uint32 для каждой геометрии).
2. Видимость берётся из `NodeOverrides`: `flags`, при `mv=1` маска — младший байт, значение — второй; узел скрыт, если `mask&1 && value&1`. В цепочках версий скрыто большинство старых источников — страница показывает только видимое.
3. `python scripts/nwd/nwd2glb.py out/ model.glb report.json`: единицы — метры (`meters_per_unit`), Z-up → Y-up, цвет из `IfcSystem` (палитра по семействам систем), изоляция полупрозрачная; иерархия «источник → категория → система → меш».
4. **Приёмка:** `python scripts/nwd/check_area.py out/ model.glb` — площадь поверхности по источникам, допуск 0,1 %. Счёт треугольников ошибку индексов НЕ ловит.
5. `python scripts/nwd/quantize_glb.py in.glb out.glb` — если файл велик: вершины int16 + `KHR_mesh_quantization`; ошибка не более 0,32 мм, размер около −22 %.
6. `python scripts/nwd/build_viewer.py assets/viewer-template.html assets/section_module.js out.html "Заголовок" "Подзаголовок"`; затем оберните результат в полный HTML-документ (с `<meta charset="utf-8">`) и при необходимости добавьте `window.SECTION_PRESETS=[{name, y}]` (отметки этажей).
7. Перед публикацией обезличьте имена в GLB: `python scripts/glb_rename_root.py in.glb out.glb "<старое>" "<новое>"` — и проверьте узлы GLB на посторонние названия.

## Ограничения

- Выбор щелчком — на уровне системы/категории; свойства элементов (расходы и т. п.) в страницу не переносятся.
- Цилиндры/окружности (типы 104/105) и точки на проверенном файле не встречались — дампер их не разворачивает.
- Подавляющее большинство сеток проверенного файла открытые (не замкнутые): заливка разреза выключена по умолчанию.
